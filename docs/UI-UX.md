# UI/UX Documentation for CBSUA Supply Office IMS

## 1. What this website is for
This website is a supply office dashboard for CBSUA. It helps staff check inventory, see what is low or out of stock, submit requests, and record received items.

It is mainly made for office staff who need to manage supplies quickly and clearly.

## 2. Main goal
The main goal is to make supply tracking easy.
Users should be able to:
- see the current stock situation
- find items fast
- review requests
- record received supplies
- know if something needs attention

## 3. Layout and structure
The page uses a simple layout with:
- left side menu for navigation
- top header with page title and user info
- dashboard area showing important data
- inventory section for supply records
- action buttons for requests and receiving stock

### Left menu
The left menu shows main sections like:
- Dashboard
- Inventory
- Stock Requests
- Issue Supplies
- Receive Stock
- Suppliers

This helps users move around the system without confusion.

### Top header
The top header shows:
- page name
- current date
- user name and role
- theme toggle button
- quick action buttons

## 4. Main screens

### Dashboard
This is the first page users see. It gives an overview of the supply office.
It shows:
- total catalog items
- pending requests
- low-stock alerts
- expiring items
- recent transaction history
- stock movement chart

This helps users know what needs attention first.

### Inventory page
This page shows all supplies in a table.
Users can:
- search by item name or category
- filter by stock status
- see quantity and status for each item

Status labels include:
- In Stock
- Low Stock
- Out of Stock

## 5. User actions
The site allows these main actions:

### New request
Users can choose an item and quantity, then send a request.

### Receive stock
Users can record the number of items received and update stock.

### Approve request
Staff can review pending requests and approve them.

### Search and filter
Users can quickly find supplies without reading the whole list.

## 6. Design style
The design is clean and easy to read.
It uses:
- green for main actions and brand identity
- white and light gray for surfaces
- dark text for clarity
- warning colors for alerts

This makes the page feel professional and organized.

## 7. Colors and readability
Colors are chosen to make information easy to understand:
- green = main actions and success
- light gray = background and neutral areas
- dark blue-gray = text
- yellow = warning/expiry notice
- red = urgent issues like out of stock

The text is large enough and has good contrast, so users can read it easily.

## 8. Ease of use
The design is simple and practical. It focuses on tasks instead of too much decoration.
Important features are placed where users expect them:
- navigation on the left
- action buttons on top
- charts and alerts on the dashboard
- inventory list in a clear table

This reduces confusion and helps users work faster.

## 9. Mobile and responsive experience
The website is designed to work on smaller screens too.
On mobile:
- the menu slides in
- content stays readable
- tables can scroll sideways
- buttons remain easy to tap

## 10. Accessibility basics
The site already follows some good practices:
- clear headings
- buttons with labels
- forms with labels
- modal dialog for request actions
- visible status messages

It can still be improved by adding stronger keyboard focus and clearer screen-reader support.

## 11. Overall UX review
This website is understandable, clean, and task-focused. It is good for office operations because it shows important information quickly.

It is best for a simple inventory system, but it still needs backend connection and real data handling to work as a full business system.

## 12. Simple conclusion
This website is designed to help supply office staff manage stock with less effort. It is easy to understand, simple to navigate, and focused on everyday tasks.

The overall experience is practical, clear, and user-friendly for a demo inventory system.
